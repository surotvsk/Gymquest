# Media credits

The exercise photographs in this folder come from **Wikimedia Commons** and are
used under the licences listed below. Each file is stored locally in this
repository and served by the app's own service-worker cache — nothing is
hot-linked and nothing is fetched at runtime, so the gallery works fully
offline.

Nine files are licensed **CC BY 2.0** (attribution required); one
(`bench-press-1.jpg`) is **public domain** (a U.S. Marine Corps work). The
creator and licence of each image are also printed in the app, directly under

## Changes made

The only change to each original file is **downscaling and JPEG re-compression**
for mobile delivery (long edge ≤ 900 px, quality ≈ 78). No cropping, retouching
or other edits were applied.
